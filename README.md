# 🥙 شاورما كيت - موقع المنيو الإلكتروني

> **ينتقي بعناية مذاق الأصالة**

موقع منيو إلكتروني احترافي لمطعم شاورما كيت في المدينة المنورة، مبني بـ Next.js 14 مع دعم RTL كامل.

---

## ✨ المميزات

- 📱 **موبايل فيرست** - مُحسَّن للجوال (max-width 480px)
- 🌙 **RTL كامل** - دعم اللغة العربية من اليمين لليسار
- 🖼️ **صور ذكية** - placeholder احترافي عند غياب الصور
- 🟢 **مفتوح الآن** - شارة نابضة تعكس ساعات العمل الحقيقية
- 🛍️ **اطلب الآن** - Modal لاختيار طريقة الطلب
- 🗺️ **Schema.org** - بيانات منظمة للسيو
- 📲 **PWA** - يمكن تثبيته كتطبيق على الهاتف

---

## 🚀 التشغيل المحلي

### المتطلبات
- Node.js 18 أو أحدث
- npm أو yarn أو pnpm

### الخطوات

```bash
# 1. استنساخ المستودع
git clone https://github.com/abdalmaged818/shawarmakit.git
cd shawarmakit

# 2. تثبيت الحزم
npm install

# 3. تشغيل خادم التطوير
npm run dev
```

ثم افتح المتصفح على: **http://localhost:3000**

## 🖼️ إضافة صور الأصناف

الصور تُحفظ في مجلد: `public/images/`

### قواعد التسمية
يجب أن يتطابق اسم الصورة **تماماً** مع الحقل `image` في `data.json`:

| الصنف | اسم الصورة |
|---|---|
| شاورما دجاج | `شاورما دجاج.jpg` |
| بوكس كيت | `بوكس كيت.jpg` |
| شاورما لحم | `شاورما لحم.jpg` |
| عصير رمان | `عصير رمان.jpg` |

### الصيغ المدعومة
`.jpg` / `.jpeg` / `.png` / `.webp`

### مثال عملي
```bash
# انسخ الصورة إلى المجلد الصحيح
cp ~/Downloads/chicken-shawarma.jpg public/images/شاورما\ دجاج.jpg
```

> **ملاحظة:** إذا لم تكن الصورة موجودة، سيظهر placeholder احترافي تلقائياً بدلاً منها.

## 🌐 النشر على Vercel (3 خطوات)


1. اذهب إلى [vercel.com](https://vercel.com)
2. اضغط **"Add New Project"**
3. اختر مستودع **shawarmakit** من GitHub
4. اضغط **"Deploy"** - بدون أي إعدادات إضافية!

### الخطوة 3: انتظر النشر
بعد دقيقتين سيكون موقعك جاهزاً على:
`https://shawarmakit.vercel.app`

## ✏️ تعديل المنيو

جميع بيانات المنيو موجودة في ملف واحد: **`data.json`**

### إضافة صنف جديد
افتح `data.json` وأضف في القسم المناسب:
```json
{
  "id": "c12",
  "name": "اسم الصنف الجديد",
  "price": 15,
  "calories": 400,
  "image": "اسم الصنف الجديد.jpg",
  "badge": null
}
```

### تعديل سعر موجود
ابحث عن الصنف في `data.json` وغيّر قيمة `"price"`.

### بعد التعديل
```bash
git add data.json
git commit -m "Update menu prices"
git push origin main
# Vercel سيُعيد النشر تلقائياً خلال دقيقة
```
